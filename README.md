# Customer Churn & Revenue Risk Dashboard

## Project Overview

This project presents an interactive Business KPI Dashboard built using Microsoft Power BI.

The dashboard analyzes customer churn, retention, tenure, payment methods, contract types, and revenue risk to provide decision-ready business insights.

## Objective

The objective is to transform cleaned customer data into clear business KPIs and interactive visualizations that help understand:

- Customer churn
- Customer retention
- Revenue at risk
- Customer tenure
- Customer segments
- Contract behavior
- Payment method patterns

## Key KPIs

The dashboard includes:

- Total Customers
- Churn Rate
- Retention Rate
- Revenue at Risk
- Average Customer Tenure

## Interactive Filters

Users can filter the dashboard using:

- Contract Type
- Tenure
- Payment Method

## Visualizations

The dashboard contains:

1. Churned Customers by Contract Type
2. Churned Customers by Tenure
3. Churned Customers by Payment Method
4. Revenue at Risk by Contract Type
5. KPI cards for major business metrics

## Tools Used

- Microsoft Power BI
- DAX
- CSV Dataset
- GitHub

## Dataset

The project uses the Customer Churn Sample dataset provided for the EdVyro data analytics task.

## Revenue at Risk Definition

Revenue at Risk represents the monthly charges associated with customers marked as churned in the dataset.

## Churn Rate Definition

Churn Rate is calculated as:

Churned Customers / Total Customers

## Retention Rate Definition

Retention Rate is calculated as:

1 - Churn Rate
